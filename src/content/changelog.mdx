## v0.1.0

The first public release of the `schema-watch` npm package.

- Local reverse proxy and live dashboard (`schema-watch start`).
- Shape diffing for type changes, removed fields, nullability, optional to
  required changes, and array item shapes, with direction-aware severity.
- Affected frontend file detection.
- CI contract checks against a committed baseline, with pull request comments,
  check runs, and SARIF output. See
  [Block breaking API changes in GitHub Actions](/guides/ci-contract-check).
- AI context briefs (`schema-watch context`).
