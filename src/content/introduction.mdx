## Publish from one source

Thally turns the same reviewed content into HTML, search, agent discovery files,
Markdown mirrors, and a read-only MCP surface — so people and AI tools read the
same, current answer. Add only the locales your readers need.

<Note type="info" title="Start with the product, not the template">
  Replace this page with the questions, terminology, and workflows your readers
  already use. Keep `docs.json` focused on the path between those tasks.
</Note>
